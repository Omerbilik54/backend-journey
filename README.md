- Polymorphism

- Interfaces

### Data Structures and Algorithms
- Basic Data Structures

- Algorithm Complexity

### Git and GitHub

## Learning Goals

- Strengthen Java programming skills.
- Improve object-oriented programming knowledge.
- Learn relational and NoSQL databases.
- Develop backend applications using Spring Boot.
- Build REST APIs.
- Understand microservices architecture.
- Gain practical experience through backend projects.
- Learn how to deploy backend applications.
